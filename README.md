# C sharp-Wearhouse-Management-App
## این یه برنامه تحت ویندوز نوشته شده با زبان سی شارپ هست که کار مدیریت انبار و صدور فاکتور خربد و فروش رو برای یه مغازه فروش لباس انجام میده

# قابلیت های این برنامه: 
## 1-احراز هویت و تشخیص کاربر مدیر از کاربر معمولی
## 2-انجام عملیات خرید و فروش کالا
## 3-انجام عملیات CRUD روی موجودیت های کالا ، کاربر و مشتری
## 4-ارائه گزارش از لیست کالا ، لیست مشتریان و فاکتور های خرید و فروش بر اساس تاریخ صدور فاکتور
## 5-امکانات تعاملی مثل تعیین تصویر زمینه برنامه

# تکنولوژی های استفاده شده در این برنامه:
## زبان C sharp
## گزارش گیری با استفاده از برنامه stimulsoft reporter
## پایگاه داده sql server
